## Question

Which links may a note carry, how are they kept safe, and how are the site's own affiliate links shown beside a note that names an alternative?

## Context

- Charted 2026-11-18. **Not worked until the developer unparks this map.**
- Developer's idea: when a commenter names an alternative the site has an affiliate link for, tag the comment's link or text with the affiliate link. Claude's caution: rewriting users' links changes their words without telling them and falls under FTC disclosure; a cleaner version shows the site's own labeled link beside the comment and leaves the user's text alone.
- Affiliate rules (chains "Alternatives and affiliate links"): never for PE-owned or PE minority stake brands; a brand's own program or a retailer program landing only on the brand's own pages; a label at every link; `rel="sponsored"`.
- Link safety to weigh: allowed schemes and domains, malware and phishing checks, `rel="ugc nofollow"`, link previews.
